# Обновление настроек дневника

- Настройки переведены из сжатой строки в полноразмерное окно с боковым меню.
- Регулярные платежи и доходы отображаются отдельными карточками с подписями каждого поля.
- Поля кредита показываются только для типа «Кредит / рассрочка».
- Статьи расходов и доходов полностью управляются пользователем: добавление, переименование и удаление.
- Названия статей сохраняются после выхода из поля или нажатия Enter.
- Убраны нестандартные синтетические начертания шрифта; используются стандартные веса 400–700 и системный Segoe UI.
- Добавлена адаптация окна настроек под узкие экраны.
