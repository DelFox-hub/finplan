# Результат инспекции архива

## Исправлено

- Удалён файл `.env` с рабочими переменными; добавлены безопасные `.env.example` и `.gitignore`.
- Удалён устаревший `tsconfig.tsbuildinfo`.
- Защищён `/auth/callback` от перехода на внешний адрес через параметр `next`.
- Загрузка данных теперь проверяет ошибки всех запросов Supabase и показывает понятный экран повторной попытки.
- Исправлена обработка ошибок при создании стартовых настроек и справочников.
- Сохранение настроек, платежей и доходов переведено на объединённую отложенную очередь: быстрый ввод больше не отправляет конфликтующие запросы и не должен перезаписываться старым ответом.
- Ошибка автосохранения больше не маскируется последующим статусом «Сохранено».
- При удалении статьи очищается `operations.category_id`, который не защищён внешним ключом в схеме.
- Добавлена обработка ошибок при сворачивании групп, перестановке операций, удалении платежей и импорте.
- Перед импортом останавливаются отложенные сохранения, чтобы они не вмешивались в замену данных.
- При миграции старых регулярных операций снятые галочки переносятся в `monthly_payment_exclusions`, затем старые дубли удаляются.
- Кредит использует поле «Оплачено»: оставшийся срок равен `Всего месяцев − Оплачено месяцев`.
- Значение «Оплачено» ограничено общим количеством месяцев.
- У кредитов окончательно игнорируется и очищается старое скрытое поле `valid_to_month`.
- Исправлена дата по умолчанию при импорте операций: используется период импортируемого файла, а не текущая настройка сайта.
- План переезда проверяет ошибки создания записи и корректно нормализует периоды строк.
- Начало/окончание строки сценария больше не могут образовать перевёрнутый период.
- Отрицательные значения gross и допвзноса в расчёте Германии ограничены нулём.
- Удалены конфликтующие и многократно продублированные CSS-правила планировщика; секция стилей собрана заново в одном месте.
- README приведён в соответствие с текущей логикой автоматических платежей и кредитов.

## Выполненные проверки

- Синтаксический разбор всех 12 файлов `.ts`/`.tsx`: ошибок нет.
- Статическая TypeScript-проверка проекта с локальными декларациями внешних модулей: ошибок нет.
- JSON-файлы конфигурации читаются корректно.
- Баланс фигурных скобок CSS: корректный.
- В итоговом проекте отсутствуют `.env`, `.next`, `node_modules` и `*.tsbuildinfo`.

## Ограничения проверки

Полный `npm run build` в контейнере не выполнен: доступный npm-реестр не содержит `@supabase/ssr`, а прямое подключение к npmjs завершилось по тайм-ауту. В архиве также нет `package-lock.json`, поэтому установка зависимостей не зафиксирована до точных версий.

Импорт выполняет несколько последовательных запросов Supabase и не является единой транзакцией. Ошибки теперь проверяются, но полная атомарность потребует отдельной серверной RPC-функции в PostgreSQL.
