# Аудит редактирования дневников и оформления

Дата: 2026-08-04

## Исправлено

- Казахстанский дневник переведён на открытое редактирование непосредственно в строках.
- Для ручных операций доступны дата, тип, статья, комментарий и сумма.
- Для регулярных платежей из дневника доступны дата платежа, статья, комментарий и сумма; изменения записываются в исходную настройку регулярного платежа.
- Кнопка редактирования и старый режим редактирования через модальное окно удалены. Модальное окно используется только для создания новой операции.
- Изменения операций сохраняются автоматически через очередь с защитой от одновременных запросов.
- Ожидающие изменения операций включены в принудительное сохранение перед импортом, выходом и другими операциями очистки очереди.
- Казахстан и Германия используют одинаковые размеры внешних колонок и панелей.
- Строки обеих таблиц уплотнены и укладываются в ширину левого блока без горизонтального выхода за его границы.
- Размеры шрифтов заголовков, подсказок, групп, строк и полей ввода согласованы между двумя разделами.
- Удалены конфликтующие повторные правила компоновки Германии.
- Исправлена ссылка на отсутствующую CSS-переменную `--ink`; теперь используется `--text`.
