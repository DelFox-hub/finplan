# Раздельные периоды просмотра

- `Дневник операций — показывать с`: задаёт нижнюю границу месяцев дневника и переключателя внутри блока дневника.
- `Календарный прогноз — показывать с`: задаёт первый месяц прогнозной таблицы независимо от дневника.
- В заголовке календарного прогноза добавлен отдельный быстрый выбор месяца начала.
- Итоги выбранного месяца дневника больше не берутся из первого месяца прогноза.
- Внутренняя дата расчёта автоматически выбирается как более ранняя из двух дат, чтобы накопительный остаток считался последовательно.

Перед запуском применить `SUPABASE_MIGRATION_REQUIRED.sql` в Supabase SQL Editor.
