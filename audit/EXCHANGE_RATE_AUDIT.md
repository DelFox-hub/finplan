# Аудит конвертации EUR/KZT

## Итог

Все рабочие расчёты переведены на автоматически получаемые курсы `mig.kz`. Ручного поля курса в интерфейсе больше нет.

## Направления конвертации

| Операция | Используемый курс |
|---|---|
| Доход в EUR → KZT | Покупка EUR у клиента (`buy`) |
| Резерв в EUR → KZT | Покупка EUR у клиента (`buy`) |
| Расход в EUR → KZT | Продажа EUR клиенту (`sell`) |
| Представление суммы KZT в EUR | Продажа EUR клиенту (`sell`) |
| Суммы, изначально заданные в KZT | Без конвертации |

## Источник курса

1. В первую очередь используется актуальный снимок, полученный общим загрузчиком `/api/exchange-rate`.
2. При временной недоступности `mig.kz` используется последний успешно сохранённый автоматический снимок.
3. Старый вручную заданный курс не принимается как резерв.
4. Старое единое поле `eurKzt` читается только для миграции данных, если запись уже помечена источником `mig.kz`, и не сохраняется обратно.

## Проверенные участки

- стартовый резерв сценария;
- доходные сценарные статьи;
- разовые сценарные расходы;
- регулярные расходы Германии;
- месячный список расходов Германии;
- календарный прогноз;
- итоговые показатели сценария;
- переключение календарного прогноза между KZT и EUR;
- информационный блок курса в шапке.
