# Исправления расчёта доходов и валюты

- Автоматические доходы «Подработка» и «Основная работа» теперь используют рассчитанное netto как фактическую сумму строки, а не сохранённый `amount = 0`.
- Для автоматических доходов валюта жёстко определяется как EUR, чтобы старые настройки строки не искажали расчёт.
- В таблицу помесячного сценария добавлены отдельные строки подработки, основной работы и остальных сценарных статей.
- Добавлен единый переключатель отображения всей помесячной таблицы: ₸ / €.
- Конвертация KZT → EUR и EUR → KZT выполняется по одному курсу из шапки (`1 € = указанный курс ₸`).
- Из названий строк таблицы убраны подписи KZT/EUR: валюта определяется переключателем над таблицей.
- В поле суммы автоматической строки отображается рассчитанное netto, поэтому больше нет визуального нуля при выбранном автоматическом расчёте.
